## 什么是虚拟联程？听起来挺玄乎

传统订机票，你要么直飞，要么选择航空公司官方的中转联程。但Kiwi.com玩出了新花样——他们开发了一套叫"虚拟联程"（Virtual Interlining）的技术。

简单说就是：航空公司A和航空公司B本来没有任何合作关系，但Kiwi.com的算法能把它们的航班拼成一个完整的行程。听上去是不是有点像拼车，但这是拼飞机。

这套技术能组合全球超过750家航空公司和交通运营商的航班，包括200多家廉价航空。你想从纽约飞到泰国某个小岛？传统网站可能只给你几个选择，而Kiwi.com能给你组合出几十甚至上百种路线。

实际效果怎么样呢？根据官方数据，他们每天处理1亿次航班搜索，2023年卖出了2500万个机票座位。数字不会骗人，说明确实有不少人在用。

## NOMAD功能：多城市旅行的神器

假设你想去欧洲玩，巴黎、罗马、巴塞罗那都想去，但不确定先去哪个城市更省钱？

Kiwi.com有个叫NOMAD的功能，专门解决这个问题。你只需要输入出发地和想去的几个城市，它会自动计算所有可能的路线组合，然后找出最便宜的那个。

这个功能在2018年推出，现在已经成为Kiwi.com的招牌之一。对于喜欢环游多个城市的旅行者来说，能省下不少钱。

## Kiwi.com保障服务：虚拟联程的保险

虚拟联程听起来很美好，但有个问题：如果第一程航班延误，导致你赶不上第二程怎么办？毕竟这两个航班原本没有合作关系，航空公司可不管你后面的行程。

Kiwi.com推出了"Kiwi.com Guarantee"保障服务来解决这个痛点。这个服务包括：

**核心保障内容：**
- **航班中断保护**：航班取消、延误或改期时，提供即时补偿或帮助申请退款
- **自动值机**：出发前24小时自动办理登机，直接收到登机牌
- **24/7即时客服**：随时可以通过AI聊天获得支持，紧急情况3小时内人工回复

有个数据挺有意思：据统计，每3个航班就有1个会延误、改期或取消。如果你订的是虚拟联程，这个保障就显得更重要了。

不过这个保障需要额外付费，通常是票价的25%左右。比如你买了200美元的机票，保障服务大概要加50美元。贵不贵见仁见智，主要看你对行程的把控能力和风险承受度。

## 怎么用才能省最多？

如果你决定试试Kiwi.com，这里有几个小技巧：

**1. 灵活的出发日期很关键**

Kiwi.com有个日历视图，能直接看到前后几天的价格对比。有时候提前一天或推后一天出发，价格能差好几百块。

**2. 利用"Anywhere"搜索功能**

**5. 仔细看中转时间**

虚拟联程的中转时间通常比官方联程要长一些，这是为了留出足够的缓冲。但如果你看到某个行程中转时间只有1小时，还要重新安检取行李，那就要三思了。

## 有哪些隐藏的省钱技巧？

除了常规的搜索功能，Kiwi.com还有几个不太为人知的小技巧：

**Hidden City售票**
这是个挺有争议的策略。比如你要从A飞到B，但你发现A到C（途经B）的机票反而更便宜。你可以订A到C的票，然后在B就下飞机，不坐后面那程。

航空公司对这个做法很不爽，有些甚至在条款里明确禁止。偶尔用用可以，但别太频繁，否则可能被航空公司拉黑常旅客账户。

**Throwaway Ticketing**
有时候往返票比单程票还便宜。如果你只需要单程，可以买往返票，然后不坐回程。同样的，这个技巧也处于灰色地带。
